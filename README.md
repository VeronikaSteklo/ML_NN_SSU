# Машинное обучение

## 1 задание

Реализация основных алгоритмов машинного обучения (регрессия, ансамбли, кластеризация) на языке Python с использованием
библиотеки NumPy. Также было проведено сравнение кастомных решений с эталонными реализациями из библиотеки Scikit-learn.

Реализованные методы:
1. KNN
2. Линейная и полиномиальные регрессии
3. Дерево решений
4. Ансамбли
5. Алгоритмы кластеризации (k-means и DBSCAN)

## Задания 2
### Задание 2.1. Кластеризация вузов

В данном задании реализован полный цикл анализа и сегментации российских вузов на основе данных мониторинга за 2015–2022 годы. Особое внимание уделено стабильности признаков во времени и качеству разделения групп.

Основные этапы:
1. **Предобработка и очистка:**
    * Объединение датасетов за разные годы с использованием нечеткого поиска (`fuzzywuzzy`) для сопоставления различающихся названий колонок.
    * Геокодинг: расчет расстояния до Москвы для каждого региона с помощью `geopy`.

    * Обработка пропусков: удаление признаков Scopus/WoS (неактуальны для 2022 года) и заполнение специфических пропусков средними значениями по конкретным вузам за прошлые периоды.
    * Группировка вузов по ведомственной принадлежности (федеральные, медицинские, транспортные и т.д.).
    * Удаление мультиколлинеарных признаков (корреляция > 0.8).
2. **Понижение размерности:**
    * Сравнение методов **PCA** и **UMAP**. Использование UMAP позволило значительно повысить качество кластеризации (Silhouette Score).
3. **Кластеризация и оптимизация:**
    * **K-Means:** Оптимальное количество кластеров ($k=8$) подобрано с помощью метода локтя и максимизации силуэта через **Optuna**.
    * **DBSCAN:** Проведен поиск аномальных организаций (шума) на основе плотности данных.

Результаты:
Выделено 8 ключевых групп, среди которых:
* **Лидеры (Кластер №2):** Крупнейшие научные центры с максимальным объемом НИОКР и доходов.
* **Экспортеры образования (Кластер №6):** Вузы с самым высоким доходом от иностранных студентов и развитыми программами ДПО.
* **Отраслевые (Кластер №3):** Профильные спортивные вузы с аномально большой площадью спортивных сооружений.
* **Слабые/Региональные:** Группы с минимальным ресурсным обеспечением.

**Инструменты:** `Pandas`, `Scikit-learn`, `UMAP-learn`, `Optuna`, `Spacy`, `Geopy`.
